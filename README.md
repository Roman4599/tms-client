# TMS Client - Training Management System Frontend

Angular 22 frontend application for the Training Management System.

## Features

- Student Dashboard with Angular Signals
- Reactive State Management using signal() and computed()
- Standalone Components - No NgModules needed
- Lazy Loading for optimal performance
- SCSS for better styling

## Prerequisites

- Node.js 20+
- Angular CLI

## Installation



## Running the Application



Open in browser: http://localhost:4200/dashboard

## How It Works

1. Student starts with 45 credits
2. Click Register for a Class to earn +3 credits
3. Credits update automatically
4. Status changes to Eligible for Graduation at 120 credits
